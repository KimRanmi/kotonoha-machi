# 주민 대화·음성·요약 — 남은 일 (2026-11-14 기준)

이번 작업(`0031`~`0033`)을 마친 뒤 남은 일을 한곳에 모았다. 확정된 일과 "정할 것"을 구분했다. 마을·주민 화면 쪽 미구현은 `chat-todo.md`를 본다.

## 1. 바로 할 일

- [ ] **백엔드 컨테이너 다시 빌드**: 마지막 수정(프롬프트 규칙 7·10, 속도 `NaN`, 맨 앞 주민 줄 건너뛰기)이 실행 중인 서버에 아직 반영되지 않았다. `docker compose up -d --build backend`.
- [ ] **실제 대화로 확인**: 편의점의 ミク가 점원으로 답하는지, 규칙 7·10이 자연스러운지. 무료 한도(모델당 하루 20회)를 아끼며 시험한다.
- [ ] **실제 소리 확인**: 높낮이를 ±3 반음으로 줄인 뒤 여성·남성 목소리가 덜 끊기는지. 모든 주민(특히 높낮이가 컸던 ミク, ソラ)을 들어 본다.
- [ ] **구글 로그인·401 확인**: 로그인 직후에도 401이 나면 쿠키 문제다. `backend/.env`에 `SESSION_COOKIE_SECURE=false`(로컬 HTTP 전용)를 추가한다. 로그인이 풀린 것뿐이면 조치 없음.

## 2. Gemini 호출 안정화 (`0033`)

- [ ] **서버 재시도**: 503(수요 폭주)·시간 초과(`InterruptedIOException`)는 일시적이라 1~2번 다시 시도한다. 가장 효과가 크다. `GeminiClient.call`.
- [ ] **오류 문구 구분**: 지금은 모두 "주민의 대답을 만들지 못했습니다"(502)다. 한도 초과(429)와 서버 바쁨(503)을 다르게 보여 준다. 백엔드 오류 코드와 `ResidentChatModal` 문구.
- [ ] **다시 시도 버튼**: 실패해도 쓴 말이 사라지지 않고 한 번에 다시 보낼 수 있게 한다(`chat-todo.md` 1절과 같은 주제).
- [ ] **응답 대기 시간(`TIMEOUT_MILLIS` 20초) 조정 여부**: 3.6은 3~14초, 느린 날은 30초 이상이었다. 재시도를 넣은 뒤 정한다.
- [ ] **404가 나는 모델들의 원인 확인**: `gemini-3.7-flash`, `3.5-flash` 등은 모델 목록에는 있지만 이 키로 호출하면 본문 없는 404가 온다. Google AI Studio에서 이 프로젝트의 사용 가능 모델·한도를 직접 확인한다.

## 3. 배포·공개 전 (포트폴리오로 운영하지 않으면 건너뜀)

- [ ] **결제 연결(유료 티어)**: 무료 티어는 모델당 하루 20회(대화+요약 합산)라 서비스용으로 부족하다. 키가 속한 Google 프로젝트에 결제를 붙이면 한도가 풀린다(요금은 확인하지 못함).
- [x] **사용자당 하루 대화 상한(악용 방지)**: 하루 200회(`ChatService.DAILY_CHAT_LIMIT`)를 넘거나 Google이 429를 주면 "주민이 졸려요" 연출이 나온다(`0035`). 서버 메모리 카운트라 재시작하면 초기화된다.
- [ ] **예산 알림·상한**: Google Cloud 콘솔에서 설정한다.
- [ ] **가입 제한**: 구글 로그인·회원가입이 열려 있어 주소를 아는 누구나 내 한도·요금을 쓴다. 본인만 쓰려면 가입을 막는다.
- [ ] **약관 확인**: 무료 티어의 입력 데이터 이용 조건과 실서비스 사용 가능 여부를 직접 확인한다.
- [ ] **TTS 요금**: Gemini와 별개다. 새로 합성하는 음성이 과금 대상이므로 하루 합성 횟수 제한을 유지한다.
- [ ] **유료 전환 시 모델·추론 설정 재검토**: 모델은 `.env`의 `GEMINI_MODEL`로 바꾼다. 추론 수준(`GeminiClient.MINIMAL_THINKING`)은 모델마다 지원 여부가 다르다(3.8은 `MINIMAL` 미지원). 바꿀 때 한 번 시험한다. `MAX_OUTPUT_TOKENS`(2048)는 과금 최악 상한이고 추론 토큰이 포함된다.
- [ ] **(선택) 요약만 더 싼 모델로**: 지금 대화와 요약이 같은 모델을 쓴다. 요약용 모델 설정을 따로 두면 비용을 줄일 수 있다.

## 4. 요약 (`0032`)

- [ ] **새 요약 형식 확인**: 항목별 핵심 사실(플레이어/약속·부탁/주민이 알려준 것/관계)이 실제 Gemini 응답에서 나오는지. 날짜가 바뀐 뒤 대화하면 실행된다.
- [ ] **하루 30줄 초과 시 손실(정할 것)**: 오늘 대화가 30줄을 넘으면 오래된 줄이 다음 날 요약 전까지 AI에게 안 보인다. 친밀도 하루 한도(+10)가 있어 드문 경우라 지금은 허용한다. 필요하면 "요약 안 된 줄이 30줄을 넘으면 최근 20줄을 뺀 나머지를 요약"을 추가한다.
- [ ] **오래된 대화 원문 정리(정할 것)**: `chat_message`는 대화할 때마다 늘어난다. 일정 기간이 지난 원문을 지우고 요약만 남길지 정한다.
- [ ] **(여러 서버로 늘릴 때) 요약 동시 실행 방지**: 지금은 서버 메모리 집합이라 서버 1대 전제다.

- [ ] **렌·아키라·소라 성별 확인**: 글에서 분명하지 않아 렌 여, 아키라 남, 소라 남으로 정했다. 아키라는 원래 말투 라벨이 "アタシ系"였는데 1인칭을 わたし로 바꿨다. 마음에 안 들면 구글 시트에서 고치고 `scripts/import-residents`로 다시 만든다.
- [ ] **ミク의 설정**: 아이돌인데 편의점 점원으로 응대한다. 어색하면 시트의 `location`이나 배경을 조정한다. 친밀도(19)는 대화를 지웠어도 남아 있다. 초기화할지 정한다.
- [ ] **규칙 9와 새 장소 종류**: 지금 장소(거리·가게·절·학교·도서관)에는 맞다. 집·공원 같은 장소가 생기면 규칙 9를 "가게라면"으로 한정한다.
- [ ] **`speech_style`·`sample_lines` 채우기**: 20명 모두 비어 있다(`chat-todo.md` 5절). 말투는 지금 `core_features` 끝 "말투:" 한 줄로 대신한다.
- [ ] **비슷한 쌍 차별화**: ダイスケ/ショウタ, ミク/レン 등(`chat-todo.md` 5절).

## 6. 코드 정리

- [ ] **안 쓰는 이전 오버로드 삭제**: `TtsService.getAudio(userId, text)`는 호출하는 곳이 없다. `GoogleTtsClient.synthesize(text, voice)`(2인자)는 기존 테스트가 쓰고 있다. 지울 때 테스트도 같이 고친다.

- [ ] **프런트 검증 한 번 더**: 리뷰어가 `speechSynthesis.ts`, `ResidentChatModal.tsx`는 읽지 못했다. 프런트 `prettier`·`lint`·`build`는 통과했다.

## 7. 개발 환경·운영 메모

- **DB 마이그레이션 번호**: 공유 DB(도커 `db`)를 여러 워크트리·브랜치가 같이 쓴다. 다른 브랜치가 같은 번호를 만들면 Flyway checksum 오류로 서버가 안 뜬다. 새 마이그레이션을 만들기 전에 다른 브랜치의 번호를 확인한다. 현재 `V33`(대화 요약), `V34`(성별), `V35`(주민 upsert).
- **`backend/.env`는 메인 폴더 파일의 링크**: 워크트리에서 고치면 메인 폴더 값도 바뀐다. `GEMINI_MODEL=gemini-3.6-flash`가 들어 있다.
- **무료 한도**: 모델당 하루 20회(한국 시간 오후 5시쯤 초기화). 시험 대화는 짧게 한다.
- **gradle 겹침 주의**: 테스트를 동시에 돌리면 `ThemeServiceTest`가 Mockito 오류로 실패한 적이 있다(재실행하면 통과). 하나만 돌린다.
