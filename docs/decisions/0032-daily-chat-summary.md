# 0032. 대화 요약은 하루에 한 번, 오늘 이전 대화만 한다

- 날짜: 2026-11-14
- 상태: 검토 중 (실제 Gemini 요약 결과 확인 전)

## 배경

- 요약(`0029`)이 최근 10줄을 뺀 오래된 줄이 10개 쌓일 때마다 실행돼 대화 5번에 Gemini 호출이 한 번씩 늘었다.
- 무료 티어는 모델당 하루 20회라서 요약이 한도를 빨리 쓴다.
- 요약이 줄글이라 이름·약속 같은 핵심을 따로 쓰기 어려웠다.

## 결정

- 요약 대상을 **오늘 0시(한국 시간) 이전**에 만들어진 줄로 바꾼다. 오늘 나눈 대화는 요약하지 않고 원문 그대로 AI에게 보낸다(요약 이후 최대 30줄).
- 오늘 이전의 요약되지 않은 줄이 10개 이상일 때만 요약한다. 한 번 요약하면 오늘 이전 줄이 모두 반영되어(`summarized_up_to_id`) 다음 날까지 다시 실행되지 않는다. 새 테이블·열은 필요 없다.
- 스케줄러는 쓰지 않는다. 날짜가 바뀐 뒤 그 주민과 처음 대화할 때 응답 후 백그라운드에서 실행한다. 대화 없는 주민은 호출하지 않는다.
- 요약 지시문을 항목별 핵심 사실(플레이어 정보, 약속·부탁, 주민이 알려준 것, 관계)로 바꾸고, 주민의 원래 설정은 적지 않게 했다.

## 대안

- 스케줄러로 매일 밤 일괄 요약: 대화하지 않은 주민까지 검사하고 설정이 늘어난다.
- 요약 간격만 늘리기(임계값 10→20): 하루 1번 보장이 없다.

## 한계

- 하루에 한 주민과 15번(30줄) 넘게 대화하면 오래된 줄이 AI에게서 빠진다.
- 요약은 AI가 만드므로 입력 대화에 잘못된 설정이 있으면 그대로 기억한다(ミク의 "집" 요약 사례로 대화 기록을 삭제했다).
