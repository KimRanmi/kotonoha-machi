# 0030. 지난 대화는 날짜별 목록으로 보여 준다

- 날짜: 2026-11-14
- 상태: 검토 중 (실제 화면에서 확인 전)

## 배경

대화창을 열면 최근 50줄이 한꺼번에 긴 스크롤로 나와(`0027`) 대화가 쌓일수록 끝없이 길어진다.

## 결정

- 대화창은 **오늘(한국 시간) 대화만** 보여 준다. `GET /api/residents/{slug}/chat`이 오늘 대화를 돌려준다(50줄 제한은 없앴다).
- 헤더의 "지난 대화" 버튼을 누르면 오늘 이전에 대화한 날의 목록(`GET .../chat/days`: 날짜·줄 수·플레이어의 첫 말 30자 미리보기, 최신 날짜부터 최대 60일)이 나온다.
- 날짜를 누르면 그날 대화만 읽기 전용으로 보인다(`GET .../chat/days/{yyyy-MM-dd}`).
- 새 테이블은 만들지 않았다. `chat_message.created_at`을 한국 시간 날짜로 묶어 목록을 만든다(친밀도의 하루 기준과 같다).

## 한계

- 60일보다 오래된 날은 목록에 나오지 않는다. 삭제·검색 기능은 없다.
- 하루 대화가 아주 많으면 그날 화면은 여전히 길다.
