# 0040. 오늘의 학습을 끝내야 주민과 대화할 수 있다

- 상태: **검토 중**
- 날짜: 2026-11-16

## 결정
- 오늘(한국 시간) 학습을 완료하지 않으면 주민 대화 전송(`POST /api/residents/{slug}/chat`)을 서버가 403(`LESSON_REQUIRED`)으로 거부한다. 프런트 입력창만 막으면 API로 우회되므로 서버에서도 강제한다(규칙은 AI가 아닌 일반 코드로 처리).
- **이동은 막지 않는다.** 마을을 돌아다니는 것이 앱의 핵심이라 막으면 첫인상이 나빠지고 얻는 것이 적다. 학습 유도는 대화만 잠가도 충분하다.
- 예외: 모든 학습을 이미 끝내 오늘 추천할 학습이 없고 오늘 완료한 것도 없으면 대화를 연다(영영 못 하는 일을 막기 위함).
- 기록 조회(GET)는 막지 않는다. 프런트는 403이면 쓴 말을 입력창에 돌려주고 "오늘의 학습하러 가기" 버튼을 보인다.

## 영향
- `requirements.md`의 "대화는 제품 제한 없음" 문장과 충돌하므로 검토 중 표시를 달았다. 확정되면 그 문장을 고친다.
- 학습 중간에 멈춘 사용자는 그날 대화가 막힌다(기준은 "완료").

## 확인 못 한 것
- 실제 화면에서 잠금 안내와 버튼 동작.
