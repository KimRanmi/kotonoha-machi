# 0033. Gemini 무료 티어의 한도와 모델 선택

- 날짜: 2026-11-14
- 상태: 확정 (개발 단계), 배포 시 재검토

## 배경

대화 중 `HTTP 429`, `503`, `400`, 시간 초과(`InterruptedIOException`)가 반복됐다.

## 확인한 것

- 무료 티어는 **모델당 하루 20회**다(429, `generate_content_free_tier_requests`). 요약 호출도 같은 한도를 쓴다.
- `gemini-3.8-flash`는 `thinkingLevel: MINIMAL`을 지원하지 않아 400이 났고, `LOW`로 바꿔도 503(수요 폭주)과 60초 무응답이 나왔다.
- 이 키로 실제 호출되는 모델은 `gemini-3.6-flash`와 `gemini-3.8-flash`뿐이었다. 다른 모델은 목록에는 있지만 호출하면 본문 없는 404가 왔다(원인 미확인).
- 이 시간대에는 3.6도 503과 무응답이 섞였다. 서버 쪽 혼잡이다.

## 결정

- 모델은 `gemini-3.6-flash`(`MINIMAL`)를 유지한다.
- 배포·공개 전에는 결제 연결(유료 티어), 사용자당 하루 대화 횟수 제한, 예산 상한, 가입 제한을 정한다. 무료 한도는 서비스용으로 부족하다.
- 포트폴리오는 운영보다 시연 영상·문서·로컬 실행 안내로 보여 준다.

## 후속

- 503·시간 초과에 대한 서버 재시도와 오류 문구 구분(바쁨/한도 초과), 다시 시도 버튼은 아직 구현하지 않았다.
