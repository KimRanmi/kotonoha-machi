# 0041. 대화 중 모르는 단어 저장 (사전 조회 + 한국어 번역)

- 상태: 구현됨, 사용자 승인(사전 API) 받음

## 결정

- 말풍선의 일본어를 드래그해 고르면 "단어장에 저장" 버튼이 뜬다. 프런트에 형태소 분석 라이브러리를 넣지 않는다(고른 글자 그대로 조회).
- `POST /api/vocabulary/chat`: 백엔드가 **jisho.org 공개 API(JMdict 기반, 키 불필요)**로 고른 표기를 조회한다. 표기(또는 가나 단어의 읽는 법)가 **정확히 일치**하는 항목만 쓴다. 못 찾으면 404로 안내한다(활용형은 기본형으로 고르라는 안내).
- 읽는 법·JLPT·영어 뜻은 사전 데이터 그대로. AI는 영어 뜻을 한국어로 **번역만** 한다(CLAUDE.md 원칙 5).
- Gemini 호출 최소화: 사전 조회 → 같은 사용자·표기·읽는 법이 이미 있으면 번역 없이 "이미 저장됨" → 아니면 번역 1회. 번역 결과는 메모리 캐시(최대 1000개). Gemini가 실패·한도 초과(429)면 영어 뜻을 그대로 저장한다(캐시하지 않음).
- 새 라이브러리·`.env` 키 없음(RestClient, 기존 `GEMINI_API_KEY` 재사용).

## 대안과 이유

- Jotoba API: 개인 서버라 안정성이 불확실해 제외.
- JMdict를 DB에 적재: 가장 안정적이지만 대용량 적재·마이그레이션이 필요해 이번 주 배포엔 과함. 사전 서버가 불안하면 이쪽으로 옮길 수 있다.

## 알려진 한계

- jisho.org는 비공식 API라 속도 제한·중단 가능성이 있다. 실패하면 502 "사전을 불러오지 못했어요"로 안내한다.
- 번역 캐시는 서버 재시작 시 사라진다. 출처 표기(JMdict, CC BY-SA 4.0)를 단어장 화면에 둔다.
