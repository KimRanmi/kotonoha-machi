# 0014. 테마 하루 1개 제한과 완료 테마 당일 열람

- 날짜: 2026-11-04
- 상태: 구현함

## 결정
- 오늘(한국 시간) 완료한 테마가 있으면 "오늘의 학습" 배너는 새 테마를 추천하지 않고, 그 완료한 테마를
  완료 상태로 돌려준다. 학습 화면에서는 완료한 테마의 한자~복습 단계를 눌러 다시 볼 수 있다(열람 모드,
  완료 처리 없음).
- 오늘 완료한 테마가 여러 개면 `updatedAt`이 가장 최근인 것을 고른다.

## 하루 1개 제한 서버 강제 (같은 날 추가)
- 처음엔 추천 로직에서만 지켰으나, URL로 직접 다른 테마에 들어가면 우회되어 서버에서도 막는다.
- `completeStage`가 오늘(한국 시간) 이미 **다른** 테마를 완료했다면 어떤 단계든 `DAILY_THEME_LIMIT_REACHED`(409)로
  거부한다. 마지막 단계에서만 막으면 하루치 학습을 다 하고 나서야 거절되므로 처음 단계부터 막는다.
- 이미 완료한 같은 테마의 재요청은 기존대로 `STAGE_OUT_OF_ORDER`다.

## 한계 (알고 둔 것)
- 두 요청이 동시에 들어오면 둘 다 검사를 통과해 하루에 둘이 완료될 수 있다(DB 제약·잠금 없음). 한 사용자가
  동시에 두 테마를 끝내는 일은 드물어 그대로 둔다.
- 프런트는 막힌 테마도 학습 화면에서 문제를 풀 수 있고, 단계를 마치고 "다음"을 누를 때 서버 메시지로 알게 된다.
- 단계 콘텐츠 조회 API(`getStageContent`)는 원래부터 진행 상태와 무관하게 열려 있다. 열람 모드는 이 API를
  그대로 쓰며 서버 변경이 없다. 비밀 데이터가 아니고 AI 호출도 없다.
- 날짜 기준은 `updatedAt`(마지막 단계 완료 시각)이다. 완료 후에는 행이 더 바뀌지 않아 완료한 날과 같다.
