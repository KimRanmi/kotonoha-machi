# 0027. 주민 대화 기록: 서버 DB(`chat_message`)에 저장하고 모달을 열 때 불러온다

- 날짜: 2026-11-11
- 상태: 검토 중 (실제 화면에서 확인 전)

## 배경

주민 대화창(모달)을 닫으면 나눈 대화가 사라진다. 다시 열었을 때 이전 대화를 보여 주고 싶다.

## 결정

- 사용자·주민별로 한 줄씩 `chat_message` 테이블(`V30`)에 저장한다(`speaker`는 `PLAYER`/`RESIDENT`, 주민 대사에는 한국어 번역도).
- `ChatService.chat`은 Gemini 대답을 받은 **뒤에** 플레이어의 말과 주민의 대답을 함께 저장한다. 대답을 못 받은 말은 남기지 않는다(짝이 맞지 않는 기록 방지).
- `GET /api/residents/{slug}/chat`이 최근 50줄을 오래된 순으로 돌려주고, 모달이 열릴 때 불러온다. 50줄 제한은 응답이 끝없이 커지지 않게 둔 값이다.
- 브라우저 저장소는 쓰지 않는다. 계정 단위로 이어져야 하고 기기·브라우저가 바뀌어도 보여야 해서 서버에 둔다(사용자가 골랐다).

## 한계

- 이전 대화를 Gemini에 보내지 않는다(여전히 단발 대화). 맥락 전달은 별도 결정이 필요하다.
- 50줄보다 오래된 기록은 화면에서 볼 수 없고, 삭제 기능도 없다.
