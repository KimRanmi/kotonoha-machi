# 0044. 모바일 대응과 숲 초록 디자인

## 배경
아이폰 Safari에서 마을 헤더의 로고가 세로로 접히고, 글자와 버튼 크기가 모바일에 맞지 않았다. 전체 디자인과 로고도 바꾸고 싶다는 요청이 있었다.

## 결정
- CSS는 웹/모바일을 나누지 않고 하나로 둔다. 기본값을 모바일 기준(터치 영역 44px, 글자 16px 이상)으로 잡고, 넓은 화면은 `@media (min-width)`로 덧붙인다.
- 색은 마을 지형과 같은 숲 초록 계열로 한다(사용자가 시안 A 크림·주황과 B 숲 초록 중 B를 선택). 색은 `theme.css` 변수 한 곳에서 바뀐다.
- 로고는 이미지 라이브러리 없이 인라인 SVG(말풍선 안의 「こ」)로 만든다.
- 헤더는 로고와 사람 버튼만 두고 나머지 메뉴는 사람 버튼의 펼침 메뉴로 모은다.
- 대화창은 모바일에서 하단 시트, 넓은 화면에서 가운데 팝업으로 보이게 한다.
- 로고용 폰트 Zen Maru Gothic은 Google Fonts 링크로 불러온다(사용자 승인 전이라 확정이 아니며, 불필요하면 시스템 폰트로 되돌릴 수 있다).

## 확인하지 못한 것
실제 iPhone Safari와 로그인 이후 화면의 모바일 렌더링.
