# 0034. 친밀도 단계별 대화 규칙은 프롬프트에 넣는다

- 날짜: 2026-11-14
- 상태: 검토 중 (실제 대화에서 단계별 차이를 확인한 뒤 확정)

## 배경

기존 규칙은 "0에 가까우면 경계, 100에 가까우면 애정 표현" 한 문장이라 중간 단계의 차이가 흐리고, 주민의 속 이야기를 언제 꺼내는지 정해 두지 않았다.

## 결정

- 시스템 프롬프트 Output Rules 2번을 4단계로 나눈다: 0~19 경계·어색(짧게 답하고 자기 이야기 거의 안 함), 20~49 평범(가벼운 잡담), 50~79 친근(먼저 질문하거나 취미·일상 이야기), 80~100 매우 반가워하고 애정 표현, 핵심 특징에 적힌 사연 같은 속 이야기를 조금씩 털어놓음(80 미만에서는 먼저 꺼내지 않음).
- 주민별 "비밀" 열은 시트에 만들지 않는다. 사연은 이미 `core_features`에 있고 규칙만 공통으로 둔다. 단계 경계 숫자는 프롬프트 문구일 뿐이라 AI가 정확히 지키는 것은 아니다.
- 성별은 `resident.gender`(`M`/`F`, `V34`)로 저장하고 프롬프트에 "성별"로 넣는다(`0031`).
- 예시 대사(`sample_lines`)와 주민별 `current_context`는 쓰지 않는다. 사용자 판단(말투는 `core_features`의 "말투:" 문장으로 충분).

## 대안

- 단계별 숫자 대신 AI가 100점 척도로 알아서 판단하게 둔다: 단계 차이가 약해 기각.
- 주민별 비밀 열: 시트 관리 부담이 커 기각.
