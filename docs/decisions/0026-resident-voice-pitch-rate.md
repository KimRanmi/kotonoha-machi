# 0026. 주민 목소리: 브라우저 내장 음성의 pitch·rate로 주민마다 다르게

- 날짜: 2026-11-11
- 상태: 검토 중 (실제 소리로 듣고 값을 조정해야 한다)

## 배경

주민 대화에서 답장을 읽어 줄 때 모든 주민이 같은 목소리로 들린다. 외부 유료 API(음성을 더 사거나 늘리는 것)는 쓰지 않고, 브라우저 내장 음성(`SpeechSynthesis`)의 `pitch`(높낮이)와 `rate`(속도)만 바꿔 성별·나이·성격 차이를 낸다.

## 결정

- 주민 상수(`lib/villageResidents.ts`)에 주민마다 `voice: { pitch, rate }`를 둔다. 어린 아이돌·가수는 pitch 1.8~1.9, 노인·거구·바텐더는 0.5~0.7처럼 준다. 값은 주민 한 줄 설명을 보고 정한 첫 추정이다.
- `speakJapanese(text, voice?)`는 `voice`를 받으면 서버 음성(Google TTS, `0013`)을 건너뛰고 브라우저 음성으로 읽는다. 서버 음성은 높낮이를 바꿀 수 없기 때문이다. `voice`가 없는 테마 학습은 이전과 같다.
- 주민 외형이 이미 프런트 상수에 있어서 목소리도 같은 곳에 둔다.

## 한계

- 브라우저·OS가 가진 일본어 음성이 달라 같은 값도 다르게 들리고, 음성 종류(남/여) 자체는 고르지 않는다. 서버 음성보다 품질이 낮다.
- 주민 추가·수정이 코드 수정이 된다. 구글 시트로 옮기려면 주민 시트에 `voice_pitch`, `voice_rate` 열을 더하고 DB 마이그레이션·`Resident` 엔티티·import 스크립트·응답 DTO를 함께 바꿔야 한다(아직 하지 않음).
